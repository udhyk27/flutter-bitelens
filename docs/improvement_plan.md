# BiteLens 개선 계획

> 최종 갱신: 2026-11-11

## 먼저 확인할 운영 항목

1. Firebase App Check에서 Android Play Integrity와 iOS DeviceCheck를 구성하고, 개발 디버그 토큰을 등록합니다.
2. Cloud Functions Secret에 `GEMINI_API_KEY`가 등록되어 있는지 확인하고 `analyzeFood`를 배포합니다.
3. 실제 Android/iOS 기기에서 카메라 촬영, 갤러리 선택, 분석, 기록 저장을 확인합니다.

이 단계는 Firebase 콘솔 및 배포 환경에 접근해야 하므로 저장소 코드 변경만으로 완료할 수 없습니다.

## 코드 개선 우선순위

| 우선순위 | 작업 | 이유 |
|---|---|---|
| 높음 | DB·검색·페이지네이션·CSV 보호 자동화 테스트 | 데이터 손상과 회귀를 조기에 발견 |
| 높음 | 대형 화면 파일을 기능별 위젯으로 분리 | 변경 영향 범위와 유지보수 비용 감소 |
| 중간 | 앱 UI 국제화 (한국어/영어/일본어) | 응답 언어 선택과 앱 UI 언어의 일관성 |
| 중간 | Cloud Function 호출량 제한/관측 추가 검토 | App Check 이후에도 비용·장애 추이를 관리 |
| 낮음 | 체중 목표, 알림, 바코드 조회 등 신규 기능 | 핵심 흐름 안정화 이후 확장 |

## 최근 반영

- 홈 통계가 전체 기록 대신 오늘 날짜의 기록만 조회
- 프로필 설정 안내 배너 공통화
- CSV 텍스트 셀 수식 주입 방지
- 기록 화면 검색·날짜 필터 및 페이지네이션, 호출 경합 방지
- App Check, 분석 재시도와 오류 상태 구분
