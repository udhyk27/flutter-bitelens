# BiteLens 코드 리뷰

> 최종 확인: 2026-11-10

## 현재 상태

- Cloud Function은 Firebase App Check 토큰을 검증하고 이미지 크기, MIME 형식, 모델명을 제한합니다.
- 클라이언트는 네트워크 오류와 일시적 서버 오류를 구분하고 제한된 재시도를 수행합니다.
- 기록 화면은 검색·기간·즐겨찾기 필터와 페이지네이션을 지원하며, 연속 필터 조회의 오래된 결과가 최신 화면을 덮지 않도록 보호합니다.
- `flutter analyze`는 2026-11-09에 통과했습니다.

## 남은 위험과 개선점

### 출시 설정 확인

App Check의 Play Integrity/DeviceCheck 등록, 개발용 디버그 토큰, Functions의 `GEMINI_API_KEY` Secret, 배포 버전은 Firebase 콘솔에서 확인해야 합니다. 설정 파일은 `.gitignore` 대상입니다.

### 홈 통계 데이터 범위

홈 화면은 로컬 기록 전체를 읽어 오늘 통계를 계산합니다. 기록이 많아질수록 불필요한 DB 읽기와 파싱이 늘어나므로 날짜 범위 쿼리가 필요합니다.

### 자동화 테스트 범위

현재 테스트는 `FoodAnalysis` 모델 중심입니다. SQLite 생성·업그레이드, 필터 조합, 페이지네이션, CSV 수식 안전 처리, Cloud Function 입력 검증을 다루는 테스트가 없습니다.

### 유지보수성 및 지역화

`result_screen.dart`, `profile_screen.dart`, `history_screen.dart`가 대형 파일입니다. 또한 설정의 분석 응답 언어와 앱 UI 언어가 별개이며, UI는 한국어로 고정되어 있습니다.

## 개선 반영 (2026-11-10)

- 홈 통계를 날짜 범위 DB 조회로 한정
- 프로필 설정 안내 배너를 공통 위젯으로 분리
- CSV의 음식명·끼니 텍스트가 스프레드시트 수식으로 처리되지 않도록 보호
- 오래된 상태 정보를 구현 현황·개선 계획 문서에서 갱신
